# 광덕 안전지도

광덕중·고등학교 캠퍼스 **2D 평면도 기반 안전신문고**입니다.
건물을 고르고 층 도면에서 위험한 위치를 찍어 신고하면, 그 자리에 핀이 꽂힙니다.

- 캠퍼스 배치도 → 건물 클릭 → 층별 평면도 (지하~옥상, 38개 도면)
- 모든 도면은 원본 CAD PDF에서 뽑은 **벡터(SVG)** 라 아무리 확대해도 선과 글자가 깨지지 않습니다
- 신고: 유형 · 위험도 · 제목 · 정확한 장소 · 내용 · 사진 · 신고자(선택)
- 처리 상태: 접수 → 처리중 → 처리완료
- 휠/핀치 확대, 드래그 이동, 치수·보조선 숨기기, 모바일 화면 지원
- 주소로 바로 열기: `#b2-1f` (덕린관 1층), `#b8` (체육관) 등

## 실행

ES 모듈과 `fetch` 를 쓰기 때문에 파일을 더블클릭하면 안 되고, 간단한 웹 서버로 열어야 합니다.

```bash
python -m http.server 5178
```

그다음 브라우저에서 <http://localhost:5178> 을 엽니다.

## GitHub Pages 로 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 를 선택합니다.
3. `https://<아이디>.github.io/<저장소>/` 에서 열립니다. (`.nojekyll` 파일이 들어 있어 그대로 동작합니다)

## 폴더 구조

```
index.html          화면 뼈대
css/app.css         스타일
js/data.js          건물 · 층 · 배치도 윤곽 · 신고 유형 데이터
js/viewer.js        벡터 도면 확대/이동 뷰어
js/store.js         신고 저장소 (지금은 localStorage)
js/app.js           화면 로직
plans/*.svg         배치도(site.svg) + 층별 평면도
tools/              PDF → SVG 변환 스크립트
```

## 신고 데이터 저장에 대해 (중요)

지금 신고는 **각자 브라우저(localStorage)에만** 저장됩니다. 다른 사람 휴대폰에서는 보이지 않습니다.
여러 사람이 같은 신고 목록을 보려면 서버 저장소가 필요하며, `js/store.js` 의
`list / add / update / remove` 만 바꾸면 됩니다. 후보:

- **Supabase** / **Firebase**: 무료 요금제로 충분, GitHub Pages 와 함께 쓰기 쉬움
- **GitHub Issues API**: 신고 1건 = 이슈 1개 (토큰 관리 필요)

그 전까지는 패널 아래 **JSON 내보내기 / 가져오기** 로 신고 목록을 옮길 수 있습니다.

## 도면 다시 만들기

원본 PDF가 바뀌면 다음 명령으로 `plans/` 를 다시 생성합니다 (PyMuPDF 필요: `pip install pymupdf`).

```bash
python tools/build_plans.py "전체배치도.pdf" "광덕중.고등학교 [면적 최종].pdf"
```

원본 PDF는 저장소에 넣지 않습니다.

## 알려진 한계

- **부3 화장실**은 배치도에 정확한 위치가 없어 지도 윤곽 없이 목록에서만 열립니다.
- 방 이름은 PDF에서 글자가 아닌 선(외곽선)으로 들어 있어 검색이 되지 않습니다. 신고할 때 "정확한 장소"에 적어주세요.
- 학교 도면이므로 저장소를 **공개(Public)** 로 둘지는 학교와 상의하세요.
