# 광덕 안전지도 (v2 · Python)

광덕중·고등학교 캠퍼스 **2D 평면도 기반 안전신문고**입니다.
화면 틀·꾸미기·동작까지 우리가 쓴 코드는 모두 파이썬(`.py`)이고 (`index.html`·`teacher.html` 은 파이썬을 불러오는 시작용 몇 줄), [PyScript](https://pyscript.net)로 브라우저 안에서 바로 실행됩니다.
그래서 따로 서버를 올리지 않아도 **GitHub Pages 링크만으로** 열립니다.

| 링크 | 누가 | 하는 일 |
|---|---|---|
| <https://ddong-jam.github.io/gwangdeok-safety-map/> | 학생 | 지도에서 건물·층을 고르고, 위험한 곳을 찍어서 신고 |
| <https://ddong-jam.github.io/gwangdeok-safety-map/teacher.html> | 선생님 | 로그인 → 대시보드 · 신고 관리 · 지도 |

학생 화면에는 선생님 페이지로 가는 메뉴가 없습니다. 선생님은 위 주소로 직접 들어갑니다.
처음 열 때는 파이썬을 불러오느라 5~10초 걸리고, 그다음부터는 빨라집니다.

## 기능

**학생용** (`index.html` + `student.py`)
- 캠퍼스 배치도 → 건물 클릭 → 층별 평면도 (38장, 원본 CAD 도면에서 변환한 벡터)
- 확대·이동 (휠·두 손가락·버튼). 도면의 130% 범위 안에서만 움직여서 길을 잃지 않음
- 연결복도 버튼: 층 도면의 연결복도 자리에 있는 파란 버튼을 누르면 이어진 건물의 같은 층으로 이동
- 검색: `2-1`, `2학년 1반`, `409`, `보건실`, `덕린관` 처럼 입력하면 그 층으로 가서 그 자리를 확대·표시 (고등 반·중학교 반·호실·방 이름·건물)
- 위험/불편 신고: 도면에서 그 자리를 바로 누르면(또는 위쪽 버튼) 신고 창이 열림 → **⚠️ 위험 / 🙁 불편** 고르기 → 유형·위험도·제목·장소·내용·사진·이름(선택). 불편 신고는 보라색 핀
- 이미 들어온 신고는 핀으로 보여서 같은 신고가 반복되는 것을 줄임 (학생에게는 신고자 이름·사진·담당자를 보여주지 않음)

**선생님용** (`teacher.html` + `teacher.py`)
- 대시보드: 처리 전 · 긴급 · 처리중 · 최근 7일 접수 · 처리 시간, 건물별/유형별/일별 그래프, 먼저 볼 신고
- 신고 관리: 상태·위험도·건물·검색 필터 → 줄을 누르면 상세
  - 상태 변경 (접수 → 처리중 → 처리완료 / 반려), 담당자, 처리 메모, 처리 기록(누가 언제)
  - 신고 위치 미리보기, 사진 보기, 삭제
  - CSV 내려받기 (엑셀에서 바로 열림)
- 지도로 보기: 층별 신고 핀을 보고 눌러서 처리

## 신고는 어디에 저장되나요?

**체험 모드 (기본값)**: `config.py` 가 비어 있으면 신고가 **그 브라우저에만** 저장됩니다.
같은 컴퓨터·같은 브라우저에서는 학생용에서 넣은 신고가 선생님용에 보이지만, 다른 학생의 휴대폰에서 넣은 신고는 보이지 않습니다.
선생님 로그인은 이름만 적으면 들어가집니다. 화면을 보여주거나 시험해 볼 때 쓰세요.

**공용 모드**: 실제로 학교에서 쓰려면 아래 "신고를 모두 함께 보기"를 설정하세요.

### 신고를 모두 함께 보기 (Supabase, 무료)

1. <https://supabase.com> 에서 새 프로젝트를 만듭니다.
2. `python tools/supabase_setup.py --copy` 로 데이터베이스 설정을 복사해서 **SQL Editor** 에 붙여넣고 **Run**.
   (v2.2.1 전에 이미 만들었다면 한 번 더 Run 하면 위험/불편 종류 칸이 더해집니다.)
3. **Authentication → Users → Add user** 로 선생님 계정(이메일·비밀번호)을 만들고,
   SQL Editor 에서 설정 맨 아래 줄의 이메일을 바꿔 실행해 선생님으로 등록합니다.
4. 학생 구글 로그인을 켭니다 (`config.py` 의 `STUDENT_LOGIN = True`, 기본값).
   - **Google Cloud Console → API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID 만들기** (웹 애플리케이션).
     *승인된 리디렉션 URI* 에 Supabase **Authentication → Providers → Google** 화면에 나오는 *Callback URL* 을 넣습니다.
   - 받은 *클라이언트 ID* 와 *클라이언트 보안 비밀번호* 를 Supabase **Providers → Google** 에 넣고 켭니다.
   - Supabase **Authentication → URL Configuration** 의 *Site URL* 과 *Redirect URLs* 에 사이트 주소
     (`https://ddong-jam.github.io/gwangdeok-safety-map/`, 내 컴퓨터 시험용 `http://localhost:5178/`) 를 넣습니다.
   - 학교 구글 계정만 받으려면 `config.py` 의 `SCHOOL_EMAIL_DOMAIN` 에 학교 도메인(예: `gwangdeok.hs.kr`)을 넣고,
     설정 SQL 을 **다시 복사해서 Run** 합니다 (도메인 규칙이 데이터베이스에 들어갑니다).
   - 학생이 처음 로그인할 때 계정이 생겨야 하므로 *Allow new users to sign up* 은 켜 둡니다.
     구글이 아닌 방법(이메일 가입)으로 만든 계정은 데이터베이스 규칙이 신고를 막습니다.
5. **Project Settings → API** 의 *Project URL* 과 *anon public* 키를 `config.py` 에 넣고 GitHub 에 올립니다.

   ```python
   SUPABASE_URL = "https://abcdefgh.supabase.co"
   SUPABASE_ANON_KEY = "eyJhbGciOi..."
   ```

   anon 키는 공개해도 되는 키입니다. 누가 무엇을 볼 수 있는지는 `tools/supabase_setup.py` 의 규칙(RLS)이 지킵니다.
   - 학생(로그인 없음): 신고 넣기 + 공개 칸(위치·유형·위험도·제목·장소·상태)만 보기
   - 선생님(등록된 계정): 모든 칸 보기 · 처리 · 삭제
   - **service_role 키는 절대 넣지 마세요.**
6. (선택) 선생님들이 계정 하나를 같이 쓰려면 `config.py` 의 `TEACHER_EMAIL` 에 그 계정 이메일을 넣습니다.
   로그인 화면에 이메일 칸이 사라지고 **이름 + 비밀번호**만 넣으면 됩니다.

### 보안 · 장난 신고 막기 (v2.5.0)

- **선생님 로그인**: 비밀번호를 5번 틀리면 3분 동안 잠깁니다. *이 기기에서 로그인 유지*를 고르면 14일, 아니면 탭을 닫을 때까지 로그인됩니다.
  로그아웃하면 서버에서도 그 로그인을 없앱니다. Supabase **Authentication → Policies(또는 Providers → Email)** 에서 비밀번호 최소 길이를 10자 이상으로 하세요.
- **신고 전 안내문**: 학생은 "사실대로 신고합니다"에 체크해야 접수할 수 있습니다.
- **자동으로 막는 것** (`guard.py`, 공용 모드에서는 데이터베이스가 한 번 더 확인):
  알아볼 수 없는 제목(ㅋㅋㅋㅋㅋ 등), 욕설, 한 기기 10분 3건·하루 10건 넘게, 같은 자리 30분 안에 다시 신고, 학교 전체 10분 60건 넘게.
- **선생님이 막기**: 신고 상세의 *장난 신고로 반려 + 이 기기 신고 막기*. 기기는 브라우저가 만든 무작위 번호라서
  브라우저 기록을 지우면 다시 신고할 수 있습니다. 생활지도와 함께 쓰세요.

## 내 컴퓨터에서 실행

```bash
python serve.py
```

- 학생용: <http://localhost:5178>
- 선생님용: <http://localhost:5178/teacher.html>

(파일을 그냥 더블클릭해서 열면 파이썬 파일을 못 불러옵니다. 꼭 `serve.py` 로 여세요.)
파이썬 파일을 고친 뒤에는 `index.html`·`teacher.html` 의 `?v=25` 숫자를, 도면(`plans/`)을 바꾼 뒤에는 `viewer.py` 의 `PLANS_VERSION` 을 올려야 브라우저가 옛날 파일을 쓰지 않습니다.

## 도면 다시 만들기

원본 PDF가 바뀌면 다음 명령으로 `plans/` 를 다시 만듭니다 (`pip install pymupdf shapely` 필요).

```bash
python tools/build_plans.py "전체배치도.pdf" "광덕중.고등학교 [면적 최종].pdf"
python tools/decorate_site.py
python tools/decorate_floors.py
```

- `decorate_site.py`: 전체 배치도를 위성사진처럼 꾸밉니다. 선을 진하게, 없어진 양궁장 지우기,
  도로·운동장(트랙·인조잔디)·중정·주차장·숲·나무 색칠.
- `decorate_floors.py`: 층별 평면도를 꾸밉니다. 교실 이름표의 과목실 이름(예: 생활수학)을 지워 `호수 / 반` 만 남기기,
  덕린관 반 표시는 크게 새로 쓰기 (반이 바뀌면 파일 위쪽 `CLASS_TEXT` 만 고치면 됨), 시설 이름 크게 (방보다 길면 두 줄로), 화장실 이름표는 선과 겹치지 않는 아래쪽 빈 곳으로 옮기기, 치수선·숫자·높이 표시(±0 등)·'홀' 지우기, 글씨 진하고 굵게, 방은 나무색·복도는 회색·화장실은 하늘색 바닥, 문은 나무색, 변기·세면대는 파란 선.

위치나 색은 각 파일 위쪽의 숫자로 바꿀 수 있습니다. 치수선은 자동으로 찾고, 자동으로 못 찾는 표시는 `decorate_floors.py` 의 `ERASE` 표에 네모로 적어 지웁니다. 교실이 아닌 방을 반으로 쓰면 `RENAME` 에 적습니다. `decorate_floors.py` 는 `build_plans.py` 로 새로 만든 도면에 한 번만 실행합니다 (이미 꾸민 도면은 건너뜀). 도면을 다시 만든 뒤에는 `viewer.py` 의 `PLANS_VERSION` 을 올립니다.

연결복도 버튼의 자리와 가는 층은 `campus.py` 의 `LINKS` 표에 적혀 있습니다 (도면 좌표).

### 검색용 방 목록 (`rooms.py`)

도면 글자는 모양(선)으로만 들어 있어서, 도면을 그림으로 바꿔 윈도우 글자 인식(OCR, 한국어)으로 읽어 `rooms.py` 를 만듭니다.
반 이름은 도면의 `<text>` 와 `tools/build_rooms.py` 의 `BLUE_LABELS` 에서, 잘못 읽은 방 이름은 같은 파일의 `FIX` 표에서 바로잡습니다.

```bash
python tools/build_rooms.py png2 2      # 배율 2·3·4·6 으로 각각 그림 만들기
python tools/ocr.py png2 ocr2.tsv          # 윈도우 글자 인식 (pip install winrt-... 는 파일 맨 위 참고)
python tools/build_rooms.py --index 2=ocr2.tsv 3=ocr3.tsv 4=ocr4.tsv 6=ocr6.tsv
```

원본 PDF는 저장소에 넣지 않습니다.

## 알려진 한계

- **부3 화장실**은 배치도에 위치가 없어 지도 윤곽 없이 건물 목록에서만 열립니다.
- 방 이름은 PDF에서 글자가 아니라 선으로 들어 있어 검색되지 않습니다. 신고할 때 "정확한 장소"에 적어주세요.
- 버전 1(HTML/JS)은 `v1.0.0` 태그에 그대로 남아 있습니다.
